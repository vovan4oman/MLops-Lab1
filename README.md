##  Опис проекту

Даний проект розроблено в рамках лабораторної роботи з налаштування професійного MLOps середовища. Головна задача — класифікація грибів на їстівні та отруйні.

У проекті імплементовано найкращі інженерні практики:

- **DVC (Data Version Control):** Версіонування наборів даних та великих файлів моделей.
- **MLflow:** Відстеження експериментів, логування гіперпараметрів та метрик.
- **Scikit-learn Pipelines:** Запобігання витоку даних (data leakage) та створення відтворюваних ланцюжків обробки.
- **Git:** Контроль версій вихідного коду.

##  Швидкий старт

### 1. Встановлення залежностей

Зклонуйте репозиторій та налаштуйте віртуальне середовище:

```bash
# Клонування репозиторію
git clone git remote add origin https://github.com/vovan4oman/MLops-Lab1.git
cd lab1

# Створення та активація віртуального середовища
python -m venv .venv

# Для Windows:
.\.venv\Scripts\activate

# Для Linux/Mac:
# source .venv/bin/activate

# Встановлення пакетів
pip install -r requirements.txt
```

### 2. Отримання даних

Оскільки датасет версіонується окремо від коду, завантажте його через DVC:

```bash
dvc pull
```

### 3. Тренування та запуск MLflow

Запустіть скрипти для тренування моделей і відкрийте панель моніторингу:

```bash
# Запуск базових експериментів
python src/models/train.py

# Тренування фінального Pipeline
python src/models/pipeline_train.py

# Запуск UI для перегляду метрик (доступно за адресою http://127.0.0.1:5000)
mlflow ui --port 5000
```

## 🛠 Troubleshooting (Вирішення проблем)

У разі виникнення помилок під час розгортання проекту:

### Помилка MIME type у MLflow (білий екран браузера на Windows)

**Симптом:** Сервер MLflow працює, але сторінка `http://127.0.0.1:5000` порожня.

**Рішення:** Відкрийте реєстр Windows (`Win + R` → `regedit`), перейдіть до `HKEY_CLASSES_ROOT\.js` та змініть значення параметра `Content Type` з `text/plain` на `application/javascript`. Перезапустіть термінал.

---

### Помилка DVC при додаванні файлів (`.csv.dvc is git-ignored`)

**Симптом:** `dvc add` скаржиться, що файл ігнорується Git.

**Рішення:** Переконайтеся, що у вашому файлі `.gitignore` після рядка `*.csv` додано виключення:

```
!*.csv.dvc
```
